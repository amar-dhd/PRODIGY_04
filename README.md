# Tic Tac Toe

A responsive black-and-white two-player Tic-Tac-Toe game built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — black-and-white theme and responsive layout
- `script.js` — turns, win/draw detection and reset logic

## Publish on GitHub Pages
1. Upload all three files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

No build step, backend, API key or dependencies are required.
